# Aurora Player —— 多格式音视频播放器（Python + PySide6）

一个功能完整的桌面音视频播放器，覆盖「多格式音频解码、视频画面播放、美观可定制的图形界面、
实时滚动歌词、文件夹导入歌单、三种播放模式、播放列表持久化」等需求。

## 一、特性一览

| 需求 | 实现方式 |
|---|---|
| 支持尽可能多的音频格式 | 三级解码后端自动降级：**ffmpeg + sounddevice**（mp3/flac/wav/ogg/m4a/aac/wma/ape/opus/aiff/mka/ac3… 几乎所有格式）→ **pygame**（mp3/ogg/wav/mid/mod…）→ **QtMultimedia**（常见格式兜底） |
| 图形化界面、可自定义、美观 | Qt Widgets 自绘圆角卡片式界面，内置 **5 套配色主题**（深空暗蓝 / 曜夜纯黑 / 樱粉轻语 / 薄荷青柠 / 奶油暖阳）一键切换，**全局字号可调** |
| 歌词实时滚动 | 自动在音频同目录查找同名 `.lrc`，按时间轴二分定位**当前句居中显示**（当前句固定在歌词区正中，上方为已播放歌词、下方为未播放歌词），**当前句切换时用缓动曲线平滑滚动过渡**而非瞬间跳变；无 `.lrc` 时自动读取**内嵌歌词**（MP3 的 USLT、FLAC/OGG/M4A 的 LYRICS/©lyr 等，音乐歌词一体），带时间轴的自动滚动，纯文本的多行静态展示；都没有时显示占位提示 |
| 双击歌词跳转播放 | 在歌词区**双击任意一句**，播放器立即跳转到该句对应的播放时间**并继续播放**：进度条、时间标签与当前句高亮同步到新位置；无时间戳的纯文本歌词、未加载歌词、未挂载文件等场景安全忽略不报错 |
| 导入音乐 | 「导入音乐」按钮：一键导入单首/多首音乐文件，或整个音乐文件夹（递归扫描），同一文件自动去重 |
| 设为系统默认播放器 | 安装时可选择把常见音频格式（mp3/flac/wav/ogg/m4a/aac/opus）与视频格式（mp4/mkv/avi/mov/webm/flv）关联到本播放器，双击音/视频文件即可直接播放 |
| 视频播放 | 支持 **mp4 / mkv / avi / mov / webm / flv** 等常见视频格式：播放时显示视频画面（优先 QtMultimedia QMediaPlayer + QVideoWidget，无 QtMultimedia 时自动降级 ffmpeg 解帧渲染并同步音频），支持播放/暂停/进度拖动；视频时长写入进度条与时间标签，歌词区对视频显示占位提示 |
| 视频拖入列表播放 | 拖拽/导入文件时自动识别视频扩展名一并加入播放列表，双击即播放；视频条目在列表中单独标记 |
| 双击打开视频播放 | 安装后注册视频扩展名（mp4/mkv/avi/mov/webm/flv）到 `AuroraPlayer.Video`，资源管理器双击视频文件即可直接打开并播放 |
| 视频双击全屏播放 | 播放视频时**双击视频画面进入全屏**，全屏下**再次双击 或 按 Esc 退出全屏**；全屏由 QVideoWidget 提升为无边框顶层窗口实现，退出后自动还原到容器布局，全屏/还原状态与 Qt 内置 Esc 行为保持同步 |
| 空格键暂停/继续 | 播放任意音/视频时**按空格键暂停，再按空格键继续播放**，与「播放/暂停」按钮等价；在输入框（如搜索、数值输入）聚焦时空格不抢键，仍可正常输入空格；视频全屏状态下同样支持空格键控制 |
| 播放列表右键菜单 | 在播放列表条目上**右键**弹出菜单：「从列表移除」（仅移出播放列表，不删磁盘文件）与「删除文件」（弹确认框，确认后把磁盘文件**移入回收站**并同步从列表移除，取消则不变更）；右键空白处不弹菜单 |
| 播放列表持久化 | 播放列表实时保存到 `%LOCALAPPDATA%\AuroraPlayer\playlist.json`，关闭程序后下次启动自动恢复（去重、过滤已删除文件，音视频条目均保留） |
| 从歌单选歌 | 双击任意歌曲立即播放，当前播放项高亮 |
| 拖拽导入并播放 | 把一个或多个音频文件 **或文件夹** 直接拖入播放器窗口，自动过滤非音频、去重，并立即播放首个拖入文件 |
| 三种播放模式 | **顺序播放 / 单曲循环 / 随机播放**，控制条一键循环切换 |

## 三、错误处理与日志（本版新增）

- **运行期未捕获异常自动落盘**：程序入口注册了全局 `sys.excepthook`，任何未捕获异常都会把完整 traceback 写入
  `%LOCALAPPDATA%\AuroraPlayer\error.log`，并弹出友好中文提示，不再出现 PyInstaller 原生英文错误框。排查问题时直接查看该日志即可。
- **打包后端依赖防护**：`numpy` / `sounddevice` 采用 try/except 惰性导入，缺失时自动降级到 pygame / QtMultimedia 后端，源码运行与打包版都不会因此崩溃；
  打包命令已通过 `--hidden-import numpy` 与 `--hidden-import sounddevice` 显式收集（对应 ffmpeg 高级后端，格式支持最全）。

## 暂停 / 恢复同步修复（本版更新）

- **现象**：播放中途「暂停」再「恢复」时，音频虽从暂停处继续，但进度条与歌词高亮一度跳回开头，与实际进度脱节。
- **根因**：① 恢复分支在引擎「未播放且未暂停」状态（降级重置/播放线程中断后）会调用 `play_stream(position_ms())`，而该位置在某些引擎下返回 0，导致从头重播并把滑块/歌词归零；② pygame 引擎 `pause_stream` 先标记暂停再读取位置，因暂停态直接返回旧 offset，实时播放位置被清掉；③ ffmpeg 后端播放失败自动降级 pygame 时无条件 `play_stream(0)` + `setValue(0)`，把 UI 强制重置到开头。
- **修复**：① `_on_play_pause` 暂停时缓存有效位置 `_paused_pos_ms`，恢复优先走 `resume_stream()`，兜底分支一律从缓存位置续播并禁用 0；② `PygameEngine.pause_stream` 改为**先读取实时 position 再标记暂停**；③ 引擎降级时从旧引擎当前位置续播（暂停态则保持暂停），不再 `setValue(0)` 重置滑块/时间/歌词；④ 每次换曲重置缓存位置。
- **回归**：play→pause→resume 连续 4 次切换，position 单调推进、暂停期间滑块与歌词停留、恢复后从原处继续（进度/歌词索引均同步）；ffmpeg→pygame 降级路径同样验证不归零。

## 三、环境与安装

- Python 3.8+（推荐 3.10+）
- 操作系统：Windows / Linux / macOS（界面代码跨平台）

```bash
# 1. 安装依赖（必需：PySide6；可选：sounddevice/numpy、pygame）
pip install -r requirements.txt

# 2. 可选：安装 ffmpeg 以获得最强格式支持
#    Windows: 下载 ffmpeg 解压后把 bin 目录加入 PATH，或放到
#             C:\ffmpeg\bin\ 下；程序会自动探测（含 ffprobe）
#    Ubuntu:  sudo apt install ffmpeg
#    macOS:   brew install ffmpeg
```

## 四、运行

```bash
python main.py
# 也可直接传入音/视频文件路径，启动后自动加入播放列表并立即播放（文件关联默认打开方式即由此触发）：
python main.py "D:\音乐\周杰伦 - 晴天.mp3"
python main.py "D:\视频\演示.mp4"
```

启动后界面底部状态栏会显示当前实际启用的解码后端：
- `ffmpeg + sounddevice`：格式支持最全（推荐装 ffmpeg）
- `pygame`：无 ffmpeg 时的降级方案（mp3/ogg/wav/mid 等基础格式）
- `QtMultimedia`：最后的兜底后端

## 五、使用说明

1. 点击「导入音乐」：选择「导入音乐文件…」可一次导入单首/多首音频文件，
   选择「导入音乐文件夹…」可递归扫描整个文件夹，自动去重后加入左侧歌单。
2. 双击歌单中的任意歌曲开始播放。
3. 底部控制条：
   - ◀ / ▶ / ▶▶：上一曲、播放暂停、下一曲
   - 进度条：拖拽或点击即可跳转进度
   - 🔊 按钮 + 音量条：调节音量 / 一键静音
   - 「顺序播放」按钮：点击循环切换 顺序播放 → 单曲循环 → 随机播放 → 顺序播放…
4. 右上角「主题」下拉框切换配色，「字号」调整全局字体大小。
5. 歌词加载优先级：**本地同名 `.lrc` > 内嵌歌词 > 占位提示**。
   - 在音频同目录放同名 `.lrc`（`song.mp3` ↔ `song.lrc`）即自动滚动高亮；
   - 没有 `.lrc` 时自动读取音乐文件内嵌歌词（音乐歌词一体）：带时间轴的
     （如 MP3 USLT 的 LRC、FLAC/OGG 的 LYRICS）按时间轴滚动，纯文本
     （如 M4A 的 ©lyr 无时间戳）以静态多行展示。

## 六、格式支持说明

- **导入扫描**：主程序按扩展名白名单（见 `player_core.AUDIO_EXTENSIONS` / `VIDEO_EXTENSIONS`）扫描，
  - 音频覆盖 mp3/flac/wav/ogg/oga/m4a/aac/mp4/wma/ape/opus/aiff/mp2/amr/mka/ac3/dts/wv/tta/mid/mod/xm/it 等 30+ 种；
  - 视频覆盖 **mp4 / mkv / avi / mov / webm / flv** 等常见格式（拖拽/导入/双击打开均支持）。
- **实际解码**取决于后端：
  - ffmpeg 后端：几乎所有 ffmpeg 支持的格式都能实时解码播放；
  - pygame 后端：仅 mp3/ogg/wav/mid/mod 等基础格式，其余在双击时会在状态栏提示无法解码；
  - QtMultimedia 后端：常见 mp3/flac/wav/ogg/m4a/aac/wma 等，并负责视频画面播放
    （QMediaPlayer + QVideoWidget；无 QtMultimedia 时视频自动降级 ffmpeg 解帧渲染 + 同步音频）。

## 八、常见问题

- **启动时报「未找到任何可用的音频后端」**：请先 `pip install PySide6`；若只装了 PySide6
  还可继续装 `pygame`（或 `sounddevice` + ffmpeg），程序会自动改用可用的后端。
- **某首歌双击没声音（pygame 后端下拉的 flac/ape 等）**：pygame 不支持该格式，
  建议安装 ffmpeg 让程序切换为最强后端。状态栏会提示具体原因。
- **双击音频文件没反应 / 无法打开**：需先运行安装程序 `setup.exe` 并勾选
  「设为常见音频文件的默认播放器」，此时 `HKCU\Software\Classes` 下各音频
  扩展名指向 `AuroraPlayer.Audio`，双击任一音频即自动打开播放器并播放该文件；
  若未勾选，可在系统「设置 → 应用 → 默认应用」中手动把音频格式关联到
  `AuroraPlayer.exe`。
- **双击视频文件没反应 / 无法打开**：安装时勾选后，`HKCU\Software\Classes` 下
  mp4/mkv/avi/mov/webm/flv 指向 `AuroraPlayer.Video`，双击任一视频即自动打开
  播放器并显示画面；也可手动把视频格式关联到 `AuroraPlayer.exe`。
- **播放列表重启后丢失**：播放列表实时写入 `%LOCALAPPDATA%\AuroraPlayer\playlist.json`；
  若该文件被删除或损坏，下次启动仅不恢复列表，不影响程序本身。
- **歌词不显示**：请确认 `.lrc` 与音频同名且在同一目录，或音频本身含内嵌歌词
  （MP3 USLT / FLAC·OGG·M4A 的 LYRICS·©lyr 等）。

## 九、技术选型依据

- **GUI 用 PySide6 而非 tkinter**：Qt 的样式表（QSS）能力让「多主题、圆角卡片、字体缩放」
  等美观/自定义需求天然可实现，且异步定时刷新歌词滚动更流畅。
- **解码「优先 ffmpeg、优雅降级」**：单一库难以覆盖 ape/wma/m4a 等全部格式，ffmpeg 是
  覆盖面最广且跨平台方案；当宿主缺少 ffmpeg 时自动退回 pygame/QtMultimedia，保证程序
  在任何环境都能至少播放基础格式，而不是安装失败即不可用。

### 黑窗 / 「找不到批处理文件」修复（本版）
历史版本在安装与卸载收尾时使用临时脚本 / 子进程方案，会残留黑色命令行窗口并弹出
「找不到批处理文件」：

| 环节 | 旧实现 | 问题 | 本版修复 |
|---|---|---|---|
| 安装建快捷方式 | `powershell -File 临时.ps1` | 子进程未隐藏，setup 运行时弹黑窗 | 改用 **wscript.exe + 临时 .vbs（UTF-16LE BOM）** 创建快捷方式：wscript 为 GUI 子系统宿主，无控制台、不弹黑窗；中文/空格路径无损；.vbs 用后即删 |
| 卸载收尾自删 | `cmd /c start /min 临时.bat`，脚本内 `del "%%~f0"` 自删 | cmd 逐行读取时 bat 已消失 → 弹「找不到批处理文件」；`start` 未加 `-` 隐藏造成黑窗残留任务栏 | 不再落盘任何 .bat/.vbs/.ps1；改为**内嵌 windowed 清理器 `aurora_cleanup_helper.exe`**（`--windowed` 打包，释放到 `%TEMP%` 后以 `CREATE_NO_WINDOW\|DETACHED` 启动），纯 Python `shutil.rmtree` 延时自删 |
| 子进程隐蔽性 | 控制台子进程未带隐藏标志 | 卸载期间弹黑窗 | 所有 `subprocess` 调用统一加 `CREATE_NO_WINDOW` 并接 `DEVNULL` |

**关键工程结论**：PyInstaller `--windowed`（无控制台）进程内 spawn 的**控制台型**
子进程（`powershell`/`cmd`）会"假执行"——进程能启动、返回码为 0，但脚本命令根本
不生效（已用探针实测证实）。因此凡需从 windowed 进程派生的动作，一律改用**同为 GUI
子系统**的宿主完成：建快捷方式用 `wscript.exe`，延后自删用自己的 `--windowed` 清理器。
